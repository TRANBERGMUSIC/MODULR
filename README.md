# MODULR

**Your tools. One platform.** Mac-værktøjer til DJs.

## Værktøjer

- **Bitrate-tjek** analyserer selve lyden og afslører filer, der er opkonverteret fra lav bitrate (fx 128 kbps gemt som 320 kbps). Den viser et spektrogram og hjælper med at finde en bedre version hos Beatport, Traxsource, Bandcamp og iTunes.

## Installation

1. Hent repoet som zip (Code → Download ZIP) og pak det ud.
2. Åbn Terminal, skriv `bash ` og træk `Installer.command` ind i vinduet. Tryk Enter.

Appen lægger sig i Programmer og opdaterer sig selv, når der kommer en ny version i dette repo.
